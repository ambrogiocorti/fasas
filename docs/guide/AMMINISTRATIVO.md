# Scheda amministrativo – una pagina

**Entrare**: password personale; da fuori struttura anche il codice dell'app sul telefono.
Il ruolo **non vede la cartella clinica**: solo presenze, rette e prospetti.

| Cosa | Dove |
|---|---|
| Presenze del mese | *Presenze*: ricavate da ingressi, ricoveri, assenze e dimissioni registrati in cartella |
| Correggere un giorno | *Presenze* → giorno → correzione con motivo (prevale sui movimenti, resta nell'audit). Meglio chiedere al coordinatore di registrare il movimento |
| Chiudere il mese per la rendicontazione | *Presenze* → «Chiudi il mese» dopo il controllo; export Excel per l'ATS |
| Rette | *Rette*: una voce per pagante (ATS, Comune, famiglia) con tariffa giornaliera e percentuali per ricovero e assenze; per un cambio di tariffa chiudere la voce e crearne una nuova |
| Prospetti | *Prospetti e incassi* → genera (bozze), controlla, **emetti** (numero progressivo), PDF ed Excel |
| Incassi | prospetto → registra incasso; gli scaduti sono elencati in alto |
| Annullare un prospetto emesso | prospetto → annulla con motivo (resta nello storico) |
| Regole di conteggio | *Rette* → impostazioni: giorno di uscita e di rientro, dati dell'ente gestore |

**Attenzione**
- Le regole di conteggio e le percentuali vanno verificate con l'ATS e con il contratto o la convenzione.
- I prospetti non sono fatture elettroniche: se servono, si esportano verso il gestionale contabile.
- Un mese riaperto dopo la chiusura richiede una motivazione, registrata.
